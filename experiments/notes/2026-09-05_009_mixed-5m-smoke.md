## 仮説と比較条件

一般日本語を主軸に、現代的な会話と医療専門語彙を少量加えた混合コーパスで事前学習すると、一般文書だけで学習した過去の5Mモデルと同程度に一般日本語を維持しつつ、会話のmarkerや医療語彙を扱えるようになると予想する。今回は原因を分離しやすくするため、モデル構造は既存のAozora 5M baselineと同じにし、データ源だけを変更する。

このsmoke実験は、性能の最終比較ではなく、混合Tokenizerから学習・checkpoint保存・生成までの一周を確認する目的である。validationはまず一般日本語の独立splitを使うため、今回のvalidation lossは一般文書寄りの指標として解釈する。会話・医療のvalidation lossは、学習が正常に終わった後に別評価として追加する。

## データと前処理

train本文は`artifacts/corpus/mixed-ja-80-10-10-v1.txt`である。seed 42、target 2,680単位、重みは一般8.0・会話1.0・医療1.0で、manifestの実採用数は一般2,129、会話276、医療275、比率は79.4403%・10.2985%・10.2612%である。一般source内の完全一致17件とsource間の重複5件を含む合計22単位は一度だけ採用した。会話markerは混合後もstart/endが276個ずつで、医療の700回challengeはtrainへ入っていない。

Tokenizerは混合train本文だけでSentencePiece Unigram、語彙数4,096を学習する。日本語の長い行と会話ブロックを落とさないため、SentencePieceの最大文長はUTF-8バイト数20,000を明示する。一般validation本文`artifacts/corpus/aozora-neko-formal-v2/val.txt`はTokenizer学習に使わない。

実行前のコマンドは次のとおりである。

```bash
.venv/bin/python scripts/train_tokenizer.py \
  --input artifacts/corpus/mixed-ja-80-10-10-v1.txt \
  --model-prefix artifacts/tokenizer/mixed-ja-80-10-10-v1-unigram \
  --vocab-size 4096 \
  --model-type unigram \
  --max-sentence-length 20000

.venv/bin/python scripts/encode_data.py \
  --tokenizer artifacts/tokenizer/mixed-ja-80-10-10-v1-unigram.model \
  --input artifacts/corpus/mixed-ja-80-10-10-v1.txt \
  --output artifacts/tokens/mixed-ja-80-10-10-v1-train.bin

.venv/bin/python scripts/encode_data.py \
  --tokenizer artifacts/tokenizer/mixed-ja-80-10-10-v1-unigram.model \
  --input artifacts/corpus/aozora-neko-formal-v2/val.txt \
  --output artifacts/tokens/aozora-neko-formal-v2-val.bin
```

学習設定は`configs/mixed-ja-5m-smoke.toml`で固定する。モデルはdim 240、6層、6 heads、context 256、MLP ratio 4、推定約5.2M parametersである。optimizerはAdamW、batch size 8、learning rate 3e-4から3e-5へのcosine decay、warmup 300、weight decay 0.1、seed 42、最大500 stepである。1 stepあたり2,048 tokenのため、総処理量は約1.024M tokenとなる。生成promptは`今日は`、sample intervalは100 stepである。

学習コマンドは次のとおりである。

```bash
.venv/bin/python scripts/train.py \
  --config configs/mixed-ja-5m-smoke.toml
```

## Tokenizerとencodeの結果

Tokenizer作成コマンドは予定どおり完了した。混合train 12,445行をSentencePieceへ渡し、skipは発生しなかった。実際の語彙数は4,096で、Unigram modelのSHA-256は`7f0496dd72d0982be8084a6e07519b269ecd006112d4270043f3f06427f02528`、vocabのSHA-256は`08bf6acfa7a10068265c28d7b2ea98120f4899e4cefa5c41ab2b58b3a84c47fc`である。

混合trainは543,569 tokenへ符号化され、binのSHA-256は`4ea1b17e0702f07207e83605e6319784254175d7080b19af43903419821c6d97`となった。一般validationは11,367 tokenへ符号化され、binのSHA-256は`201c45c2479f3ede43b92d938ab3a9c8e95a087c5627e906f52d393fc6a39f4f`となった。いずれもvocab size 4,096、EOS ID 3である。Tokenizerのmetadataとencode metadataはそれぞれのartifactディレクトリに保存されている。巨大なmodel、vocab、bin本体はGit管理対象外である。

想定した「日本語の長い行や会話ブロックを落とさない」という条件は、SentencePieceのログで12,445文すべてを読み込んだことにより満たされた。次はこの固定済みToken列で500 stepの学習を実行する。

## 成功条件

Tokenizerが入力をskipせずに作成され、train・validationのToken数とSHA-256がmetadataへ残ること。500 stepまでNaN、OOM、途中停止なく完走し、checkpoint metadataを使ってreloadできること。step 0、100、200、300、400、500の生成文が`artifacts/samples/mixed-ja-5m-smoke/`に保存されること。lossが全く下がらない場合や生成が崩れる場合も失敗として記録する。

## 実行結果

Tokenizer作成、encode、学習はすべて完了した。学習は500 stepまでエラー、NaN、OOM、途中停止なく完走し、所要時間は114.90秒であった。stepごとの主要値は次のとおりである。

| step | train loss | validation loss | validation perplexity |
|---:|---:|---:|---:|
| 1 | 8.7245 | 8.8279 | 6,821.63 |
| 100 | 5.6592 | 6.7204 | 829.17 |
| 200 | 5.3147 | 6.3877 | 594.51 |
| 300 | 5.9898 | 6.0773 | 435.87 |
| 400 | 4.0155 | 5.8600 | 350.71 |
| 500 | 4.2838 | 5.7469 | 313.22 |

最良checkpointは`artifacts/checkpoints/mixed-ja-5m-smoke/step_000500.npz`で、validation loss 5.7468989690、perplexity 313.2178544429である。checkpointをreloadして`evaluate.py`で再計算した値も同一であり、保存と復元は確認できた。metricsは`artifacts/checkpoints/mixed-ja-5m-smoke/metrics.jsonl`、summaryは`artifacts/checkpoints/mixed-ja-5m-smoke/summary.json`に保存されている。

学習途中の生成文は、step 0から500まで100 stepごとに`artifacts/samples/mixed-ja-5m-smoke/step_*.txt`へ保存した。step 0ではランダムな文字列だったが、step 500では`今日はまだは気味に行きまってる。`のように、日本語の語彙と文末らしさは現れた。ただし、一般promptに医療問題のラベルや数値が続く生成、`吾輩は`に対する「御御」の反復などもあり、意味のある日本語を安定して生成できる段階ではない。

reload後には、一般・物語・会話・医療を意識した追加生成も保存した。代表例は[reloaded-today.txt](../../artifacts/samples/mixed-ja-5m-smoke/reloaded-today.txt)、[reloaded-story.txt](../../artifacts/samples/mixed-ja-5m-smoke/reloaded-story.txt)、[reloaded-conversation-v2.txt](../../artifacts/samples/mixed-ja-5m-smoke/reloaded-conversation-v2.txt)、[reloaded-medical.txt](../../artifacts/samples/mixed-ja-5m-smoke/reloaded-medical.txt)である。会話promptの初回ファイル`reloaded-conversation.txt`は、シェル引数で改行を文字列の`\\n`として渡してしまった記録であり、削除せず残したうえで、実改行を渡した`reloaded-conversation-v2.txt`を追加した。

過去のAozora単独5M smoke（実験005）のstep 500 validation lossは5.5770で、今回の5.7469は約0.17高い。ただし、Tokenizerと学習データが同時に変わっているため、混合データの悪化とTokenizer差を分離した比較ではない。このsmokeの主な成果は、会話・医療を含む混合trainからTokenizerを作り、5Mモデルの学習と生成を最後まで通せたことである。医療promptの出力は専門語彙を含むが、正解性は評価していないため、医療知識を獲得したとは解釈しない。

次は会話validationと医療validationを別々に符号化してdomain別lossを測定し、一般・会話・医療の差を記録する。その後、一般日本語sourceを増やして80/10/10を維持できる混合データを作り、同じ5M構成で比較する。現代的な構成は、まず現行absolute position embedding＋LayerNormを基準として固定した後、RoPEだけを変更する別実験へ進む。

## domain別評価の追加計画

domain別評価入口を`089eba3`で追加した。既存checkpointを変更せず、一度ロードしたモデルを一般・会話・医療のvalidation Token列へ順に適用し、結果を`artifacts/evaluations/mixed-ja-5m-smoke-domains.json`へ保存する。会話validationは`artifacts/corpus/conversation-v1/validation.txt`、医療validationは`artifacts/corpus/medical-qb-v2/validation.txt`から、実験009と同じTokenizerで符号化する。これらのvalidation本文はTokenizer学習にもcheckpoint学習にも使わない。

```bash
.venv/bin/python scripts/encode_data.py \
  --tokenizer artifacts/tokenizer/mixed-ja-80-10-10-v1-unigram.model \
  --input artifacts/corpus/conversation-v1/validation.txt \
  --output artifacts/tokens/mixed-ja-conversation-val.bin

.venv/bin/python scripts/encode_data.py \
  --tokenizer artifacts/tokenizer/mixed-ja-80-10-10-v1-unigram.model \
  --input artifacts/corpus/medical-qb-v2/validation.txt \
  --output artifacts/tokens/mixed-ja-medical-val.bin

.venv/bin/python scripts/evaluate_domains.py \
  --config configs/mixed-ja-5m-smoke.toml \
  --checkpoint artifacts/checkpoints/mixed-ja-5m-smoke/step_000500.npz \
  --domain general=artifacts/tokens/aozora-neko-formal-v2-val.bin \
  --domain conversation=artifacts/tokens/mixed-ja-conversation-val.bin \
  --domain medical=artifacts/tokens/mixed-ja-medical-val.bin \
  --output artifacts/evaluations/mixed-ja-5m-smoke-domains.json
```
